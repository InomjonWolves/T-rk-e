# Türkçe Yoʻl — loyiha xulosasi (yangi sessiya uchun)

Oʻzbek tilida soʻzlashuvchilar uchun turk tilini oʻrgatadigan bepul, mobil uchun moʻljallangan PWA sayt.
- Sayt: https://inomjonwolves.github.io/T-rk-e/ (GitHub Pages). Qisqa manzil: Firebase Hosting, sayt nomi `firebase.json` → `hosting.site` (hozir `turkceyol` → https://turkceyol.web.app; `pamuk` nomi band edi). Joylash `.github/workflows/firebase-hosting.yml` orqali `main` ga har push'da (avval testlar); GitHub secret `FIREBASE_SERVICE_ACCOUNT` boʻlmasa oʻtkazib yuboriladi. Sayt nomi band boʻlsa, konsolda boshqa nom bilan sayt yaratib, `firebase.json` dagi `site` ni oʻzgartiring. Yangi domen Firebase Authentication → Authorized domains da boʻlishi kerak.
- Repo: InomjonWolves/T-rk-e, `main` branch. GitHub Pages `main` ildizidan avtomatik joylanadi (build yoʻq, oddiy statik fayllar).
- Foydalanuvchi bilan **faqat oʻzbek tilida** gaplashing.

## Joriy holat — qisqa xulosa (2026-11-02)
**Tayyor va saytda:** A1–B2 kurs, qoʻllanma va 675 ta qoida mashqi; 4 koʻnikma (Okuma, Dinleme, Yazma, Konuşma) boʻyicha mashqlar, hisob va `#skills` paneli; tinglash (TTS) va gapirish (mikrofon) mashqlari; erkin yozishni avtomatik tekshirish; 4 qismli daraja testlari; darajani aniqlash testi; tinglash va gapirish xatolar daftari; anonim analitika (`#admin`). Firestore qoidalari konsolda joylangan (test hisobi bilan tekshirildi), foydalanuvchi `admins/{uid}` hujjatini yaratdi. 41 ta avtomatik test, GitHub Actions'da ham ishlaydi.

**turkceyol.web.app — ishlayapti (2026-11-02):** sayt `turkceyol` (`pamuk` band edi), `firebase.json` → `site: "turkceyol"`, GitHub secret `FIREBASE_SERVICE_ACCOUNT` bor; workflow `Firebase Hosting` `main` ga har push'da joylaydi (birinchi muvaffaqiyatli joylash workflow_dispatch bilan). Service account rollari: Firebase Hosting Admin, API Keys Viewer, Cloud Run Viewer, **Service Usage Consumer** (busiz 403 `serviceusage.services.get`). Authentication → Authorized domains da `turkceyol.web.app` boʻlishi kerak. Sandbox `*.web.app` ni ochmaydi — saytni foydalanuvchi tekshiradi; joylanganini workflow logidagi `sites/turkceyol/versions/...` dan bilish mumkin.

**Firestore qoidalari (guruhlar bilan) konsolda joylangan** (2026-11-02) va haqiqiy Firestore'da tekshirildi: `python3 -I tools/check-rules.py` — 3 ta vaqtinchalik hisob ochadi, 25 ta holatni sinaydi (guruh yaratish, qoʻshilish, begona kira olmasligi, chiqarish, eski qoidalar), oxirida hammasini oʻchiradi. `firestore.rules` oʻzgarsa, foydalanuvchi konsolda qayta joylaydi, keyin shu skript.

**Keyingi mumkin boʻlgan ishlar (foydalanuvchi tanlaydi):** guruhga topshiriq berish (oʻqituvchi boʻlim/mashq belgilaydi); tezlik davomi (endi asosiy toʻsiq `app.js` 80 KB gzip; `guide.js`/`grammar-ex.js` ni kechiktirish uchun `GX_CODES`, `GUIDE_ALL` ni dangasa qilish kerak); .uz domeni (tavsiya `turkceyol.uz`, olinmagan); push eslatmalar (pullik Blaze tarifi kerak, keyinga qoldirilgan).

**Ish tartibi:** `ccr-…` branch'da ishlash → `npm test` → commit → push → `main` ga fast-forward merge → uchta workflow (`Testlar`, `Firebase Hosting`, `pages build and deployment`) yashil ekanini tekshirish.

**Muhit cheklovlari:** sandbox tarmogʻi koʻp saytlarni toʻsadi (sinavmultilevel.uz, MyMemory, `*.web.app`, domen RDAP/cctld.uz). `firestore.googleapis.com` va `identitytoolkit.googleapis.com` ochiq. Firebase konsoliga kirish yoʻq — konsol ishlarini foydalanuvchi qiladi.
