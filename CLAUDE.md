# Türkçe Yoʻl — loyiha xulosasi (yangi sessiya uchun)

Oʻzbek tilida soʻzlashuvchilar uchun turk tilini oʻrgatadigan bepul, mobil uchun moʻljallangan PWA sayt.
- **Yagona manzil: https://turkceyol.web.app** (Firebase Hosting, sayt `turkceyol`, `firebase.json` → `hosting.site`). Joylash `.github/workflows/firebase-hosting.yml` orqali `main` ga har push'da (avval testlar; secret `FIREBASE_SERVICE_ACCOUNT`). Eski GitHub Pages nusxasi (`inomjonwolves.github.io/T-rk-e`) faqat yoʻnaltiradi: `index.html`, `privacy.html` va statik sahifalar boshidagi `/* Yagona manzil */` skripti oʻsha sahifaga turkceyol.web.app da oʻtkazadi (test: `data.test.js`). Saytda boshqa manzil koʻrsatilmaydi (test tekshiradi; faqat tasdiqlash xati yuboruvchisi `noreply@t-rk-e.firebaseapp.com` istisno). Firebase'ning `t-rk-e.firebaseapp.com` domeni hozircha Google kirish oynasi uchun ichkarida ishlatiladi (`authDomain`) — `AUTH_SAME_DOMAIN` yoqilgach u ham kerak boʻlmaydi.
- Repo: InomjonWolves/T-rk-e, `main` branch (build yoʻq, oddiy statik fayllar). GitHub Pages hali yoqilgan boʻlsa, faqat yoʻnaltirish uchun; foydalanuvchi uni Settings → Pages da oʻchirishi mumkin (shunda eski havolalar 404 beradi).
