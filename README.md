# Türkçe Yoʻl

Oʻzbeklar uchun turk tilini oʻrganish sayti: 36 ta dars (A1, 539 ta soʻz va ibora), 10 ta grammatika mavzusi, takrorlash tizimi (SRS), xatolar daftari, kartochkalar, testlar, yozish mashqi va talaffuz.

Fayllar: `index.html` (sahifa), `styles.css` (dizayn), `app.js` (dastur), `content.js` (darslar), `grammar.js` (alifbo va grammatika), `grammar-ex.js` (A1 qoidalar mashqlari, qoʻllanma mavzulari boʻyicha), `course.js` (A1–B2 kurs: 32 boʻlim, lugʻat, mashqlar, testlar), `cat.js` (brend mushukcha Pamuk va animatsiyalari), `guide.js` (grammatika qoʻllanmasi, sayt dizaynida), `firestore.rules` (Firestore qoidalari).

Bitta statik sahifa (`index.html`), hech qanday server talab qilmaydi. Telefonga ilova sifatida oʻrnatiladi va internetsiz ham ishlaydi.
