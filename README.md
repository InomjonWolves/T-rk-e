# Türkçe Yoʻl

Oʻzbeklar uchun turk tilini oʻrganish sayti: 36 ta dars (A1, 539 ta soʻz va ibora), 10 ta grammatika mavzusi, takrorlash tizimi (SRS), xatolar daftari, kartochkalar, testlar, yozish mashqi va talaffuz.

Dars mazmuni `content.js` faylida.

Bitta statik sahifa (`index.html`), hech qanday server talab qilmaydi. Telefonga ilova sifatida oʻrnatiladi va internetsiz ham ishlaydi.
