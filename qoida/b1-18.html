B1.18 Orttirma nisbat (-dir, ‑t)

Ettirgen çatı

FİİL + DIr / tFEʼL + -dir / -t

Shakllar

OʻzakQoʻshimchaMisol
undosh bilan tugagan-dır / -dir / -tır / -tiryap → yaptır, kes → kestir, öl → öldür
unli, l yoki r bilan tugagan (koʻp boʻgʻinli)-toku → okut, bekle → beklet, otur → oturt
istisnolar-Ir, -Ar, -Itiç → içir, çık → çıkar, kork → korkut

Qoida

Ishni birovga qildirishni bildiradi. Tuzilishi: X-A Y-I yaptırmak — X ga Y ni qildirmoq: Saçımı berbere kestirdim.

Misol

Saçımı berbere kestirdim.

Sochimni sartaroshga oldirdim.
